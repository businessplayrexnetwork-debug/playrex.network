PLAYREX NETWORK — PHASE 1 DEMO

Implemented:
1. Demo Google/player/organizer login session.
2. Organizer application workflow.
3. Admin review panel.
4. Approve / Reject organizer applications.
5. Approving an application automatically adds a tournament to Tournament Showcase.
6. Admin can publish News / Updates.
7. Local browser storage preserves demo data.

This is still a DEMO. Google OAuth, secure admin authentication, database storage and real public hosting must be connected for production.
